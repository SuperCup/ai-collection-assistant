# AI采集助手（采集君）

引导用户从零跑通 AI 自动化采集：检测环境 → 判定方案 → 安装工具 → 配置中转站 → 验证链路 → 安装扩展 → 下达指令 → 完成采集。

## 类型

Agent 型（单个 AI 专家）

## 定位

面向**不懂技术的运营、市场、数据同事**。核心价值有两块：

1. **把工具链配好** —— 环境检测、方案路由、工具安装、中转站接入、扩展安装、链路验证，全程陪同，逐步确认。
2. **把指令下清楚** —— 把用户的口语需求翻译成结构化、可执行、带验收标准的采集指令，让 AI 工具一次跑对。

## 核心能力

| 能力 | 说明 |
|------|------|
| 环境体检 | 检测操作系统、浏览器、已装工具、网络连通性，输出体检报告 |
| 方案路由 | 按网络条件与订阅情况，推荐 ChatGPT Computer Use 或 WorkBuddy 浏览器链路 |
| 网络判定 | 实测境外站点连通性，决定软件从官方源还是国内镜像获取 |
| 工具安装 | 引导安装 ChatGPT 桌面版、cc-switch、Codex CLI 等 |
| 中转站配置 | 引导获取并填写 Base URL / API Key，替用户完成配置文件改写与连通性实测 |
| 链路验证 | 分别验证 ChatGPT 本体与 CLI 工具链路 |
| 扩展安装 | ChatGPT 官方扩展 + WorkBuddy 浏览器扩展 |
| 采集引导 | 生成结构化采集指令，引导打开工作页面并完成采集与验收 |
| 问题急救 | 35 条高频 FAQ，覆盖六大环节 |

## 两条采集路线

| 路线 | 方案 | 前提 | 特点 |
|------|------|------|------|
| **A** | ChatGPT Computer Use | 可访问境外站点 + ChatGPT 付费订阅 | AI 直接操控浏览器；Windows 上前台接管，任务时无法做别的事 |
| **B** | WorkBuddy 浏览器链路 | 无需翻墙 | 零额外成本，完全国内可用 |

## 内置技能

- `env-check` —— 环境检测（含 Win/Mac 双平台 Python 脚本，支持 `--json` / `--quick`）
- `toolchain-setup` —— 工具安装与中转站配置
- `collection-runbook` —— 采集指令生成与执行引导
- `faq-troubleshooting` —— 常见问题与解决方案库

## 使用示例

- "帮我检测环境，配置一套能用的 AI 采集工具链"
- "我的网络访问不了外网，怎么在这台电脑上跑自动化采集？"
- "采集任务跑到一半报错了，帮我排查一下"

## 安全说明

- 绝不把用户的 API Key、账号密码写入任何会分享的文件
- 绝不推荐来源不明的软件（破解版/汉化版/绿色版）
- 绝不绕过付费与授权限制
- 专家包内不含任何硬编码的密钥或内部地址
