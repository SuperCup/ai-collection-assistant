# AI采集助手（采集君）

引导用户从零跑通 AI 自动化采集：检测环境 → 判定方案 → 安装工具 → 配置中转站 → 验证链路 → 安装扩展 → 下达指令 → 完成采集。

## 类型

Agent 型（单个 AI 专家）

## 定位

面向**不懂技术的运营、市场、数据同事**。核心价值有两块：

1. **把工具链配好** —— 环境检测、方案路由、工具安装、中转站接入、扩展安装、链路验证，全程陪同，逐步确认。
2. **把指令下清楚** —— 把用户的口语需求翻译成结构化、可执行、带验收标准的采集指令，让 AI 工具一次跑对。

## 核心能力

| 能力 | 说明 |
|------|------|
| 环境体检 | 检测操作系统、浏览器、已装工具、网络连通性，输出体检报告 |
| 方案路由 | 按网络条件与订阅情况，推荐 ChatGPT Computer Use 或 WorkBuddy 浏览器链路 |
| 网络判定 | 实测境外站点连通性，决定软件从官方源还是国内镜像获取 |
| 工具安装 | 引导安装 ChatGPT 桌面版、cc-switch、Codex CLI 等 |
| 中转站配置 | 引导获取并填写 Base URL / API Key，替用户完成配置文件改写与连通性实测 |
| 链路验证 | 分别验证 ChatGPT 本体与 CLI 工具链路 |
| 扩展安装 | ChatGPT 官方扩展 + WorkBuddy 浏览器扩展 |
| 采集引导 | 生成结构化采集指令，引导打开工作页面并完成采集与验收 |
| 问题急救 | 35 条高频 FAQ，覆盖六大环节 |

## 两条采集路线

| 路线 | 方案 | 前提 | 特点 |
|------|------|------|------|
| **A** | ChatGPT Computer Use | 可访问境外站点 + ChatGPT 付费订阅 | AI 直接操控浏览器；Windows 上前台接管，任务时无法做别的事 |
| **B** | WorkBuddy 浏览器链路 | 无需翻墙 | 零额外成本，完全国内可用 |

## 内置技能

- `auto-update` —— 自动更新与本地注册刷新（启动时先检查更新，再开始服务）
- `env-check` —— 环境检测（含 Win/Mac 双平台 Python 脚本，支持 `--json` / `--quick`）
- `toolchain-setup` —— 工具安装与中转站配置
- `collection-runbook` —— 采集指令生成与执行引导
- `faq-troubleshooting` —— 常见问题与解决方案库

## 自动更新（用户侧零操作）

本专家包托管在 GitHub：`https://github.com/SuperCup/ai-collection-assistant`

**每次新会话启动时，专家会自动：**

1. **检查更新** —— 对比本地版本与 GitHub 生产分支（main）的版本
2. **有更新则自动更新** —— 下载最新专家包并覆盖本地（多源下载，国内网络免代理）
3. **刷新本地注册** —— 同步本地市场索引信息，保证专家中心展示与最新一致
4. **热加载最新指令** —— 当前会话立即按最新流程继续，无需重启 WorkBuddy
5. **然后才开始** —— 进入环境体检、配置、采集的正常流程

**用户无需任何操作**，也无需关心 git。更新失败时静默降级为使用当前版本继续服务，不阻塞使用。

| 特性 | 说明 |
|------|------|
| 多源下载 | GitHub 直连失败自动切换国内加速镜像（ghfast.top 等） |
| 防降级保护 | 本地版本高于远程时拒绝更新，避免通道混用误覆盖 |
| 只增不删 | 更新只做覆盖+新增，永不删除本地文件（防误删） |
| 根标记校验 | 更新前校验专家包根完整性，防脚本被误放到异常路径 |
| 体验通道 | 白名单用户可从 test 开发分支获取体验版 |

## 作者维护（发布新版本）

```bash
cd <专家包目录>
git checkout test                    # 默认在 test 开发
# ... 修改内容 ...
# 若要发布：更新 .update-version.json 与 plugin.json 的 version 后
git add -A && git commit -m "..."
git checkout main && git merge test && git push origin main
git checkout test
```

> ⚠️ 发布前务必确认：包内**无密钥、无内部地址、无本机路径**，且 `plugin.json` 与 `.update-version.json` 的 version 一致。

## 安全说明

- 绝不把用户的 API Key、账号密码写入任何会分享的文件
- 绝不推荐来源不明的软件（破解版/汉化版/绿色版）
- 绝不绕过付费与授权限制
- 专家包内不含任何硬编码的密钥或内部地址
